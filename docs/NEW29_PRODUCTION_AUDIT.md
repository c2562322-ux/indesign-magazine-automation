# 신규 29페이지 제작 차단 일괄 분석

2026-10-01. 정적 코드/모델 분석이며 Adobe 통과/Production Ready를 의미하지 않는다. 기존 Library와 모델을 수정하지 않았다. 재현: tools/audit-production-library.js에 Library 경로와 source SHA256을 전달한다. 모든 텍스트 프레임(미확정 포함)의 정책을 분석한다.

## 공통 정책

동일 paragraph/character style 참조와 동일 effective typography에서 상속/직접 지정 표현만 다른 경우 uniform 교체를 지원한다. 차이가 있는 raw key 모두가 resolved 값에 존재해야 한다. 미해결 override/다른 named style/실제 크기·행간·색·자간 차이는 차단한다. 기존 문자 종류별 언어 정책은 유지. 콘텐츠 교체 전 원본 Fidelity와 교체 후 typography/overflow 검사를 변경하지 않는다.

현재 확정 역할의 혼합 Typography는 6페이지: 목차 TITLE 2페이지(굵기 차이), BODY 4페이지(크기/행간 차이). 언어-only 문제로 분류하지 않는다. 2쪽 u335e는 첫 글자21pt/나머지13pt. 4·6·7쪽 BODY는 첫글자18pt/이후11pt, 행간25/19이며 마지막 변경 위치가 원문 문자수61 또는65에 묶여 있어 새 DOCX에 안전한 의미 대응 근거가 없다. 우세 run으로 평탄화하거나 원문 offset/비율을 새 원고에 복사하지 않는다.

## 최소 Adobe 테스트

테스트 가능한 페이지: 표시3(u3356),5(u3d6),10(u577b),11(u577c),12(u853e),13(u8668). 새 모델 실기 성공 아님. 원고 사진 수/부제 등 조건이 일치해야 카드에서 제작 가능하다. 동일 DOCX를 모든 페이지에 강제로 적합 처리하지 않는다.

사진3장 원고가 있다면 5쪽 u3d6 한 개만 먼저 테스트: Reload → DOCX → 추천 → 새 샘플 5쪽 이 디자인으로 제작. 나머지25개/29개를 사용자가 모두 반복 검사할 필요는 없다. 실패 시 카드 원인/진단 JSON 하나 전달. 사진 수가 다른 DOCX라면 아래 표 슬롯 수에 맞는 테스트 가능 디자인을 선택한다. 4쪽은 여전히 차단이 정상이다.

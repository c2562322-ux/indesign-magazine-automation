# 실제 InDesign 검증 순서 — 1.1

**아래는 아직 실행하지 않은 수동 검증 항목입니다.** Node/Host double 테스트 통과와 구분하세요.

각 결과에 OS, InDesign 정확한 버전, UDT 버전, 폰트 이름, 입력 파일, 생성 페이지 수, 스크린샷, 오류 메시지를 남깁니다.

| 순서 | 입력/동작 | 기대 결과 |
|---|---|---|
| 1 | UDT에서 manifest 등록·로드 | 새 디자인 패널 표시. 기존 양식 모드 전환/복귀 가능 |
| 2 | Freesentation 폰트 설치, 예시 원고로 무료 시안 생성 | 3안의 제목 위치/크기·단 구성 차이 확인 |
| 3 | 원래 작업 문서 열어두고 새 문서 생성 | 새 문서만 생성. 기존 문서의 프레임/내용 그대로 |
| 4 | 짧은 본문·사진 없음 | 모든 원문 표시, 불필요한 빈 본문 페이지 없음 |
| 5 | 8,000자 이상 본문 | 본문 연결 및 자동 페이지 추가. 원문 누락/중복 없음 |
| 6 | 제목 또는 부제를 매우 길게 입력 | 설계 단계 또는 생성 후 검수에서 오류 표시. 글자 자동 축소 없음 |
| 7 | PNG 1장, JPG 2장 | 선택한 모든 사진이 각 1회 배치, 비율 유지 크롭. 사람이 얼굴/주요피사체 확인 |
| 8 | 사진 선택 후 원본 파일 이동 | 새 문서 생성 전에 중단. 기존 문서 변경 없음 |
| 9 | 설치 안 된 폰트 입력 | 새 문서 생성 전에 오류 |
| 10 | A4/B5 변경, 본문 9/10.5/12pt | 판형·여백·단 수·연결 페이지 확인 |
| 11 | Word 일반 문단, 탭, Shift+Enter | 패널 추출 결과가 원문과 일치 |
| 12 | Word 표/각주/변경 추적 또는 중복 마커 | 누락하며 진행하지 않고 명시적으로 거부 |
| 13 | 원고·시안 저장 후 불러오기 | 원고/설정/선택 시안 복원, 키 미포함, 사진 경로 확인 |
| 14 | 문서 생성 뒤 원고 수정 | 새로 생성하기 전 이전 제작본 출력 버튼 비활성화 |
| 15 | 생성 문서를 사람이 수정 후 검사 | 최신 넘침/링크/폰트 상태 반영 |
| 16 | 생성 문서의 텍스트를 넘치게 만든 뒤 PDF | PDF 출력 차단, 수정용 INDD 저장 허용 |
| 17 | INDD 저장 / PDF 내보내기 | 선택 경로 저장, PDF 옵션 창 표시, 실제 PDF 페이지/글자 대조 |
| 18 | 원래 문서로 포커스를 바꾼 뒤 패널 저장 | 이 패널에서 만든 문서만 저장됨 |
| 19 | 생성 도중 place 실패 등 Host 오류 | 새 불완전 문서만 정리. 사용자 기존 문서가 닫히지 않음 |
| 20 | 생성 후 한 번 Undo | UXP/호스트 버전에 따른 실제 Undo 범위 기록. 원본 문서 편집 보존 |
| 21 | API 키와 사용 가능한 모델 입력 후 AI 버튼 | 명시한 전송 범위만 1회 호출, 1개 시안 추가 |
| 22 | 같은 원고/설정으로 AI 버튼 재클릭 | 세션 캐시 재사용, 재호출 없음 |
| 23 | 잘못된 키/한도초과/무효 좌표 응답 | 오류 표시, 자동 재시도 없음, InDesign 문서 미생성 |

PDF 검수는 인쇄소 프로파일/재단/오버프린트/유효 해상도 기준으로 별도 수행합니다. 기본 검사 통과를 인쇄 품질 보증으로 표시하지 마세요.

## 수용량과 차단 정책

기존 geometry, inset, columns/gap, font size, leading, tracking, scale, paragraph spacing 및 CJK 비율 기반 저신뢰 범위 계산을 유지했다. 원본 Story의 문자 수/문단 수와 단독 프레임 여부를 근거로 추가한다. 원본 Story가 여러 프레임에 걸치면 전체 원문 분량을 개별 프레임 수용량으로 취급하지 않는다.
